AIsa (legal name AIPAY INC.) provides a resource layer for AI agents, aggregating companies, people, keywords, AI answers, listings and posts into a unified schema. The platform offers a searchable API that delivers structured data about entities and AI-generated answers, enabling developers to integrate comprehensive knowledge graphs into their applications. It aims to simplify AI agent development by centralizing diverse data sources into one accessible endpoint.

**Areas:** Company · AI · Data · Platform · Knowledge-Graph · API

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for aisa-one: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
